## Project Overview
The Grill House is a bar and grill restaurant website developed for the WEDE5020 POE.
The website provides customers with information about the restaurant, its menu, table bookings,
enquiries and contact details.

## Website Goals and Objectives
- Create a simple and user-friendly restaurant website.
- Provide easy access to menu and restaurant information.
- Allow customers to submit table booking requests.
- Allow customers to send enquiries.
- Improve the restaurant's online presence.

## Part 3 - Enhancing Functionality and SEO

### JavaScript Enhancements

The Grill House website was improved using JavaScript to make it more interactive and user-friendly.

- Added an interactive map using Leaflet.js and OpenStreetMap.
- Added a food gallery with a lightbox that enlarges images when clicked.
- Added a dynamic menu search feature to help users find dishes.
- Added category filtering for burgers, grilled meals, sides and drinks.
- Improved the enquiry form with JavaScript validation and error messages.
- Improved the contact form with input validation and Formspree integration.
- Added response messages to provide feedback to users.

### Search Engine Optimisation (SEO)

The following improvements were made to help search engines understand the website:

- Added unique page titles and meta descriptions.
- Included relevant keywords in the website content.
- Used appropriate headings to organize page information.
- Added descriptive alt text to gallery images.
- Added lazy loading to gallery images.
- Created robots.txt to allow search engine crawling.
- Created sitemap.xml to list the six website pages.
- Used responsive design to support mobile and desktop devices.

The sitemap URLs will be updated after the website is deployed.
